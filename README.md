# Computer Vision using Python

This repository contains the **source code and practical examples** for studying Computer Vision and its applications using Python.

Most of the materials are provided as **Jupyter Notebooks**, using a variety of libraries and frameworks for image processing, computer vision, robotics, and related applications.

## Contents

The repository covers topics including:

* Computer Vision
* Image Processing
* OpenCV
* TensorFlow
* PyTorch
* Robotics
* Spatial Mathematics and transformations with SpatialMath
* Other related Computer Vision and Robotics techniques

The code ranges from fundamental Computer Vision concepts to more advanced implementations involving machine learning, deep learning, image analysis, and robotic systems.

## Notes

* Most code is provided as **Jupyter Notebook (`.ipynb`) files**.
* The repository focuses on **practical implementation and experimentation** with Computer Vision and Robotics.
* Multiple Python libraries and frameworks are used depending on the topic and application.
* More examples and implementations may be added over time.
